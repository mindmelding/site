LoyaltyOverlayBot

Last updated October 21, 2026. LoyaltyOverlayBot is the crawler behind Loyalty MCP, a free tool that tells people whether a restaurant they already visit has a rewards program they could join.

How to recognize it

User agentLoyaltyOverlayBot/1.0 (+https://mindmelding.dev/lmcp/bot)
SignaturesRequests carry HTTP message signatures (Web Bot Auth, Ed25519) with Signature-Agent: "https://loyalty-overlay.fly.dev". Our public key is at https://loyalty-overlay.fly.dev/.well-known/http-message-signatures-directory.
Runs fromFly.io (region sjc). We don't use proxies or rotate IP addresses.

What it fetches

  • A restaurant's public rewards signup data on Toast (www.toasttab.com/<restaurant>/loyalty/sign-up-data). We keep only three facts: whether rewards are on, the earn rate shown, and the public signup link. We use the restaurant phone number on that page only to match records.
  • Toast's public restaurant directory pages (toast.app/cities/<city>/all) and restaurant sitemaps (toast.app/r/sitemap-index.xml), to learn which restaurants exist.

It only sends GET requests. It never logs in, never touches account, ordering or checkout pages, never submits forms and never collects anything about diners.

How fast

  • Signup data: once a week, one request at a time, at most one request per second.
  • Directory pages and sitemaps: once a week, one page every 1 to 3 minutes (a few hundred pages a week).

Rules it follows

  • It reads robots.txt before crawling a site and skips anything disallowed for LoyaltyOverlayBot or *. If robots.txt can't be read, it doesn't crawl that site.
  • If a site blocks it, shows a challenge or CAPTCHA, or answers 403, 429 or 503, it stops the whole run and waits until next week. It never solves CAPTCHAs or tries to get around a block.
  • If a site owner asks us to stop, we stop.

Blocking it

User-agent: LoyaltyOverlayBot
Disallow: /
