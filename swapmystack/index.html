How it works

01

It reads your stack

Your storefront, your theme file and the bills export from Shopify admin. No login, no keys.

02

It prices the swaps

Each paid app gets a cheaper stand-in if one holds up, with what you'd lose and how hard the move is.

03

Your assistant walks the switch

Exports, the new vendor's import, the checks, and cancelling the old app last. You say yes at every gate.

Card details stay with the vendors

Payment tokens, SMS consent and points balances move vendor to vendor. Swap My Stack never holds them.

Nothing goes out without your yes

Every email to a vendor is a draft until you approve it by name.

Keys never pass through chat

When a step needs an API key, it reads it from your machine. Your assistant never asks you to paste one.

Set up Swap My Stack

It runs on your own computer and needs Python 3.10 or newer.

  1. Install it.
    pipx install git+https://github.com/mindmelding/swapmystack
  2. Add it to your assistant. For Claude Code:
    claude mcp add swapstack -- swapstack mcp
    Other assistants: add an MCP server that runs swapstack mcp.
  3. Ask it: "Audit my store." Or skip the assistant and run it in your terminal:
    swapstack audit yourstore.com --bills bills.csv

The bills export is in Shopify admin under Settings, Billing, Export bills. The audit works without it, but it can't show dollar figures.
